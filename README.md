# Desenvolvimento Front-End I

Este repositório reúne as atividades e projetos que desenvolvo durante a disciplina de Desenvolvimento Front-End I, do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS) do Instituto Federal do Espírito Santo (IFES).

O objetivo é registrar minha evolução nos estudos e colocar em prática os conhecimentos adquiridos ao longo do curso.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

### Destaque: Lista de Tarefas com JavaScript

Aplicação desenvolvida para praticar os primeiros conceitos de JavaScript e manipulação do DOM.

Funcionalidades:
- Adicionar tarefas a uma lista.
- Validar campos vazios.
- Criar elementos HTML dinamicamente.
- Limpar o campo após adicionar uma tarefa.
